# Temperature Converter GUI

A lightweight Desktop GUI application built in Python using Tkinter to convert temperatures between Celsius, Fahrenheit, and Kelvin.

## Features
- **3-Way Conversion:** Switch seamlessly between Celsius (°C), Fahrenheit (°F), and Kelvin (K).
- **Interactive GUI:** User-friendly window with input validation.
- **Keyboard Shortcut:** Press `Enter` to run conversions instantly.

## How to Run
1. Run `python main.py` in your terminal.
